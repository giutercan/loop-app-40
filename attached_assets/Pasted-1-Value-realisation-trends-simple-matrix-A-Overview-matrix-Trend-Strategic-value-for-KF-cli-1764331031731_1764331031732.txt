B. Quick colour on each trend for you

I’ll keep it tight – think “talk track bullets”, not thesis.

1. Outcomes & shared KPIs

Realisation move: standardise a Value Canvas in the tool:

Client North Star (12–24 months)

3–5 value outcomes (Grow / Optimise / De-risk / Strengthen Capability)

Baseline, target, timeframe, benefit owner per KPI

Why this is feasible: the structure is already implied in your Discovery → Alignment flow, KPI libraries and financial engine.

Impact: forces every engagement to answer Jerry’s “In a year, what does success look like and how will we measure it?” in a disciplined way.

2. Value-linked commercials

Realisation move: don’t jump to “we get 20% of your uplift”.

Start with evidence-rich fixed fees + optional success fees on controllable leading indicators (e.g. adoption, completion, manager quality of coaching).

Use existing ROI models (SIOP, selection, development) as underwriting logic.

Impact: sharper commercial stories, better defence when procurement wants discounting, and a path to more adventurous models once the data bedrock is there.

3. Value Realisation Offices / value governance

Realisation move:

A small, central “Value Office” curating: KPI libraries, benefit maps, financial bridges, templates.

“Value leads” in each major solution line who adapt those templates (e.g. one for SIOP, one for Sales Effectiveness, one for Leadership).

The Value Lifecycle Platform = their operating environment.

Impact: you get away from “Giuliana has an amazing spreadsheet” and into “KF has a recognisable way of doing value realisation”.

4. CS-style health scores & QBRs

Realisation move:

Use the health-score idea (on track / at risk / off track) against each value outcome.

Encode QBR templates in the platform: pull KPI deltas + narrative + next-loop recommendations.

Impact: you stop having opinion-only “how do you feel it’s going?” reviews, and you have a repeatable backbone for Review & Renew.

5. AI-assisted real-time value

Realisation move:

You already have AI for research, KPI suggestions and value narratives. Extend it to:

propose early-warning flags when KPIs stall,

auto-draft updated value stories before exec reviews,

suggest “if this KPI is lagging, similar clients did X”.

Impact: consultants spend their time interpreting and influencing, not wrangling data. It also gives you a tech story that’s credible, not buzzwordy.

6. Hard quantification of people/HR value

Realisation move:

Take the logic from your ROI Estimation slide (selection accuracy, development lift, turnover changes, etc.) and generalise it into reusable impact ranges and bridges to financials.

Align those with the Grow / Optimise / De-risk / Strengthen Capability frame so sellers don’t need to be amateur quants.

Impact: you occupy the space between “soft people stuff” and “hard outcomes” (which is exactly where no one has cracked closed-loop value capture yet, as Jerry said).
